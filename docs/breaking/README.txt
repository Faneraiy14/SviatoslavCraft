Несумісні зміни версій Voxelin.

Файл <версія>.txt (напр. 1.4.0.txt) - по рядку на кожну зміну, після якої щось
старе перестає працювати: формат світу, протокол без старого, прибране API модів,
змінена поведінка скриптів. ./ship.sh <версія> бере рядки з цього файлу в
versions.json ("breaking"), а гра й сервер показують їх у «Є оновлення» всім,
хто стрибає через цю версію. Немає файлу - несумісних змін немає.
