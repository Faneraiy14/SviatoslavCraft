Несумісні зміни версій Voxelin.

Файл <версія>.txt (напр. 1.4.0.txt) - по рядку на кожну зміну, після якої щось
старе перестає працювати: формат світу, протокол без старого, прибране API модів,
змінена поведінка скриптів. ./ship.sh <версія> бере рядки з цього файлу в
versions.json ("breaking"), а гра й сервер показують їх у «Є оновлення» всім,
хто стрибає через цю версію. Немає файлу - несумісних змін немає.

Нумерація версій (semver, прийнято 09.11.2026)
- 1.4.x -> 1.4.(x+1): лише виправлення. Світи, мережа й моди - як були.
- 1.x -> 1.(x+1): новий вміст і можливості. Гравці з 1.x заходять один до одного
  (Protocol.MIN_VERSION не піднімається), моди під 1.x вантажаться (VoxelinApi.MIN_COMPATIBLE
  не піднімається), старі світи відкриваються. Файлу <версія>.txt тут нема.
- 2.0.0: щось старе перестає працювати - гра по мережі зі старими версіями, моди
  під 1.x, формат світу. Тоді ж з'являється docs/breaking/2.0.0.txt.
Правило перевіряється перед ./ship.sh: якщо піднято MIN_VERSION чи MIN_COMPATIBLE -
це 2.0, а не 1.x.
